개인정보처리방침

fishcut이 어떤 정보를 어디에 저장하고 어디에 쓰는지 설명합니다. fishcut은 사용자의 컴퓨터에서 실행되는 소프트웨어이고, 운영자는 사용자의 영상, 토큰, 지표를 저장하지 않습니다.

시행일 2026-10-27 / 마지막 갱신 2026-11-27

현재 실행본의 처리와 한계를 설명합니다. 종료하거나 잠든 컴퓨터에서는 자동 삭제와 Google 확인을 실행할 수 없습니다. 이 방침의 발행은 Google, Meta, TikTok의 심사 통과나 오프라인 삭제 기한의 예외 승인을 뜻하지 않습니다. 실행 조건은 8절, 저장 보호는 7절을 확인해 주세요.

1. 이 방침이 적용되는 곳

이 방침은 Apache-2.0 오픈소스 macOS 데스크톱 영상 편집기 fishcut(데스크톱 앱과 명령줄 도구)과 이 웹사이트에 적용됩니다. fishcut의 운영자는 개인사업자 에이든(대표자 안승원)이며, 사업자 정보는 운영자 페이지에 있습니다.

  • fishcut은 사용자의 컴퓨터에서 실행됩니다. 영상, 프로젝트, 토큰, 지표는 이 컴퓨터에 저장되며 운영자의 서버로 보내지 않습니다. 운영자가 운영하는 서버는 Instagram과 TikTok 연결에 쓰는 인증 중계 서버 하나뿐이고, 3절에서 설명합니다.
  • 운영자가 등록한 Google Cloud 프로젝트로 연결하면 Google 동의 화면에 앱 이름 fishcut이 표시되고 이 방침이 적용됩니다.
  • Instagram과 TikTok 연결은 운영자가 등록한 Meta 앱과 TikTok 앱, 또는 사용자가 직접 등록해 fishcut에 넣은 앱을 씁니다. 그 서비스의 동의 화면에는 앱 이름이 표시되고 이 방침이 적용됩니다.
  • 사용자가 직접 만든 OAuth 클라이언트로 연결하면 그 Google Cloud 프로젝트는 사용자가 관리합니다. 이때도 fishcut 소프트웨어가 정보를 다루는 방식은 이 방침과 같습니다.

2. YouTube API Services 사용

fishcut은 연결한 YouTube 채널을 확인하고 사용자가 확인한 영상을 올리기 위해 YouTube API Services를 사용합니다. YouTube 기능을 쓰면 Google 개인정보처리방침도 함께 적용됩니다. YouTube 서비스 약관은 이용약관에서 설명합니다.

3. Instagram, Facebook, TikTok API 사용

Instagram과 TikTok 연결은 선택 기능입니다. 이 계정들을 연결하지 않으면 fishcut은 아래 정보를 다루지 않습니다. 연결하면 fishcut은 사용자가 확인한 영상을 그 계정에 올리고, 올린 영상과 계정의 지표를 읽어 지표 화면에 보여 줍니다. 이 기능을 쓰면 Meta 개인정보처리방침과 TikTok 개인정보처리방침, 각 플랫폼의 개발자 약관도 함께 적용됩니다.

TikTok

fishcut이 TikTok에서 하는 일은 업로드와 지표 읽기입니다.

  • 업로드: 사용자가 확인 버튼을 누른 영상을 TikTok Content Posting API로 연결한 계정에 보냅니다. 기본은 TikTok 받은편지함에 초안으로 보내는 방식(video.upload)입니다. 사용자가 연결할 때 따로 켠 경우에만 프로필에 바로 게시하는 방식(video.publish)을 쓰며, 이때 공개 범위는 사용자가 직접 고르고 기본값이 없습니다. 받은편지함 초안은 사용자가 TikTok 앱에서 캡션과 공개 범위를 정해 직접 게시합니다.
  • 지표 읽기: 지표 화면에 연결한 TikTok 계정 자신의 지표만 읽어 보여 줍니다. TikTok Display API로 계정의 팔로워 수, 팔로잉 수, 전체 좋아요 수, 영상 수와 영상별 조회수, 좋아요, 댓글 수, 공유 수를 읽습니다. 계정 소유자가 TikTok API for Business(Accounts API) 접근을 승인한 경우에는 같은 계정의 프로필 지표와 영상 인사이트(조회수, 좋아요, 댓글, 공유, 평균 시청 시간, 완주율, 유입 경로)도 그 API로 읽습니다. 이 접근은 계정 소유자가 TikTok의 동의 화면에서 승인한 뒤에만 시작되고, TikTok에서 언제든 취소할 수 있습니다.

TikTok에 요청하는 권한은 다음과 같습니다.

  • user.info.basic: 계정의 이름과 ID를 보여 주려고 씁니다.
  • user.info.stats: 팔로워 수, 팔로잉 수, 전체 좋아요 수, 영상 수를 지표 화면에 보여 주려고 씁니다.
  • video.list: 계정의 영상 목록과 영상별 숫자를 읽어 지표 화면에 보여 주려고 씁니다.
  • video.upload: 받은편지함에 초안을 보내려고 씁니다.
  • video.publish: 사용자가 연결할 때 바로 게시를 따로 켠 경우에만 요청합니다.

fishcut은 프로필 소개글처럼 user.info.profile 권한이 필요한 정보와 TikTok의 메시지, 다른 사람의 계정 정보를 읽지 않습니다.

Instagram과 Facebook

  • 업로드: 연결한 Instagram 프로페셔널 계정에 Facebook Login for Business 방식의 Instagram API로 사용자가 확인한 영상을 릴스로 올립니다. 릴스는 게시하는 즉시 공개됩니다. 약 50초를 넘는 릴스는 Instagram이 파일 직접 전송을 받지 않으므로, 사용자가 Google Drive를 연결한 경우에 한해 영상을 사용자의 Google Drive(drive.file)에 올리고 링크가 있는 모든 사용자가 볼 수 있게 공유한 주소를 Instagram에 보냅니다.
  • 지표 읽기: 연결한 계정의 게시물 목록과 좋아요, 댓글 수, 팔로워 수, 릴스와 계정의 인사이트(조회, 도달, 평균 시청 등)를 읽습니다. 사용자가 댓글 읽기 권한을 허용한 경우에는 게시물의 댓글 글도 읽으며, 댓글을 쓴 사람의 이름은 읽지도 저장하지도 않습니다.
  • 권한: instagram_basic, instagram_content_publish, pages_read_engagement, pages_show_list는 사용자가 관리하는 Facebook 페이지와 거기에 연결된 Instagram 계정을 찾고 릴스를 올리는 데 씁니다. instagram_manage_insights와 instagram_manage_comments는 선택 권한이며 지표 읽기에 씁니다.
  • fishcut은 Facebook과 Instagram의 메시지와 친구를 읽지 않습니다. 사용자가 레퍼런스 탐색에 팔로우 계정으로 등록하고 새로 고침을 누른 공개 비즈니스 계정의 릴스(캡션 첫 줄, 게시일, 조회수, 좋아요, 댓글 수)는 Instagram 공식 API로 읽을 수 있고, 이 값은 연결한 계정의 지표가 아니라 사용자의 레퍼런스 후보로 이 컴퓨터에 저장됩니다.

TikTok 갱신 토큰은 이 서버가 암호화(봉인)해 돌려주므로 사용자의 컴퓨터에는 봉인된 값만 저장됩니다. 이 서버는 토큰, 로그인 코드, 영상, 지표, 개인정보를 저장하지 않고 요청 내용을 기록하지 않습니다. 남기는 것은 경로별 요청 수와 결과 코드, 남용을 막으려는 계정과 기기의 가명 ID뿐이고 3개월 동안 둡니다. 사용자는 고급 설정에서 직접 등록한 앱 클라이언트로 연결해 이 서버를 거치지 않을 수 있습니다.
  • fishcut은 TikTok, Instagram, Facebook에서 읽은 정보를 판매하거나 제3자와 공유하지 않습니다. 운영자가 받지 않으므로 사용자들의 정보를 합치지 않으며, 크리에이터 탐색, 순위, 광고, 프로필 작성, 신용 평가, AI나 머신러닝 모델 학습에 쓰지 않습니다. 지표는 연결한 계정의 소유자 본인에게 지표 화면에서 보여 주는 데만 씁니다.
  • 사용자가 AI 에이전트에게 지표를 읽게 하면 그 에이전트 제공자의 서비스가 읽은 내용을 받을 수 있습니다. 어떤 에이전트를 쓸지, 지표를 읽게 할지는 사용자가 정합니다(6절). fishcut은 토큰을 에이전트에 넘기지 않습니다.
  • TikTok 접근은 TikTok에서 직접 취소할 수 있습니다. TikTok 설정이나 TikTok 앱의 설정, 보안, 앱 권한 관리에서 fishcut을 제거합니다. 삭제와 취소는 9절에서 설명합니다.

보관 기간은 8절, 삭제와 권한 취소는 9절에서 설명합니다.

5. 정보를 쓰는 목적

  • 업로드할 채널과 계정의 이름을 화면에 보여 주어 사용자가 맞는 채널인지 확인하게 합니다.
  • 사용자가 확인 버튼을 누른 영상을 사용자가 정한 설정으로 연결한 채널(YouTube, Instagram, TikTok)에 올립니다.
  • 예약 업로드 뒤 영상의 공개 상태와 예약 시각이 요청한 값과 같은지 다시 확인해 보여 줍니다. 예약하지 않은 업로드는 업로드 응답을 결과로 기록합니다.
  • 올린 영상과 연결한 계정의 지표를 읽어 지표 화면에 보여 주어, 사용자가 자기 영상이 어떤 성과를 냈는지 확인하게 합니다.
  • 사용자가 fishcut CLI와 스킬로 호출하는 AI 에이전트가 영상 기획과 업로드 준비를 도울 수 있도록, 연결한 채널의 이름과 업로드 기록을 에이전트가 읽게 합니다(6절).

fishcut은 이 정보를 광고, 프로필 작성, 판매, 신용 평가에 쓰지 않습니다.

6. 공유와 전송

  • fishcut은 위 정보를 운영자의 서버로 보내지 않습니다. 3절의 인증 중계 서버를 거치는 로그인 연결, Google, Meta, TikTok 요청, 사용자가 연결한 AI 에이전트와 음성 공급자에 대한 전송은 아래와 같습니다.
  • YouTube 채널 확인, 업로드, 지표 읽기 요청은 사용자의 컴퓨터에서 Google로 HTTPS를 거쳐 바로 갑니다. 중간 서버는 없습니다.
  • Instagram과 TikTok의 업로드와 지표 읽기 요청도 사용자의 컴퓨터에서 Meta와 TikTok으로 바로 갑니다. 로그인 연결과 TikTok 토큰의 갱신과 폐기만 3절의 인증 중계 서버를 거칩니다.
  • 사용자가 fishcut CLI와 스킬로 호출하는 AI 에이전트(Claude Code, Codex 등)는 이 컴퓨터에 저장된 정보 가운데 영상 프로젝트, 채널 설정(채널 이름, 기획 설정, 업로드 기본값, 기본 목소리, 게시 일정, 연결한 채널의 이름), 업로드 기록(채널 이름, 시각, 공개 범위나 예약, 영상 주소, 보낸 제목, 고정 댓글)과 사용자가 읽게 시킨 지표를 읽을 수 있습니다. 어떤 에이전트를 연결할지는 사용자가 정하며, 그 에이전트 제공자의 방침이 함께 적용됩니다. fishcut은 토큰을 에이전트에 넘기지 않습니다. Instagram 댓글 글은 에이전트가 읽는 지표에 넣지 않고, 사용자가 직접 요청한 경우에만 이 컴퓨터의 CLI가 돌려줍니다.
  • 사용자가 유료 음성 공급자(Typecast, ElevenLabs 등)를 고르고 승인하면, 음성을 만들 문장이 사용자의 API 키로 그 공급자에게 전송됩니다. 이때 그 공급자의 방침이 적용됩니다. 이 전송에 Google 사용자 데이터는 들어가지 않습니다.

7. 저장 위치와 보호

  • 상태 폴더는 fishcut을 실행한 사용자만 읽고 쓸 수 있는 권한(폴더 0700, 파일 0600)으로 만듭니다.
  • Google, TikTok, Instagram 토큰과 앱 비밀은 macOS Keychain에 저장하고 상태 폴더의 파일에는 두지 않습니다. 명령줄에 값이 보이지 않도록 Keychain에 쓸 때 표준 입력으로 넘깁니다.
  • 채널 정보, 게시 기록, 지표, 사용자가 작성한 자료와 프로젝트 파일은 상태 폴더와 작업 폴더의 파일로 저장하며 fishcut이 따로 암호화하지 않습니다.
  • Google, Meta, TikTok과의 통신은 모두 HTTPS로 암호화됩니다.
  • 로컬 편집기와 데몬은 기본으로 이 컴퓨터의 주소(127.0.0.1)에서만 접속을 받고, 시작할 때 받은 토큰으로 연 창과 브라우저만 쓸 수 있습니다. 사용자가 원격 접속을 직접 켜면 그 설정을 따릅니다.

8. 보관 기간

fishcut은 연결한 채널 확인, 사용자가 승인한 업로드, 지표 화면에 필요한 정보를 이 컴퓨터에 저장합니다. 아래 자동 처리는 fishcut이 실행 중일 때만 작동합니다.

정보보관 기간
YouTube 채널 ID와 이름, OAuth 갱신 토큰주기적으로 연결을 확인하고 성공한 실제 시각을 기록합니다. 마지막 확인부터 30일이 지난 정보와 토큰은 유지보수 실행 시 삭제합니다. 실패한 확인이나 재시작으로 확인 시각을 연장하지 않습니다.
YouTube 업로드 결과, 영상 ID와 주소, 업로드 세션 URL, 중복 전송 확인용 해시생성부터 30일이 지난 기록은 유지보수 실행 시 함께 삭제합니다. 채널 재확인으로 기록의 보관기한을 연장하지 않습니다. 편집기에서 연결을 철회하면 관련 기록은 철회 뒤 7일 안에 로컬에서 삭제합니다.
YouTube 지표읽은 지 30일이 지난 것은 fishcut이 실행 중일 때 삭제합니다. 연결을 해제하면 7일 안에 삭제합니다.
Google 취소 요청에 실패한 갱신 토큰연결 사용을 막고 재시도에만 사용합니다. 철회 시작부터 7일이 지난 토큰은 유지보수 실행 시 삭제합니다. 로컬 삭제는 Google 권한 취소 성공을 뜻하지 않습니다.
Instagram 페이지 토큰, TikTok 토큰, 함께 저장한 계정 ID와 이름사용자가 채널 연결을 해제하거나 Keychain에서 지울 때까지 보관합니다. 연결을 해제하면 토큰을 바로 지웁니다. TikTok 갱신 토큰은 TikTok이 정한 유효 기간(발급 뒤 최대 365일)이 지나면 쓸 수 없습니다.
TikTok과 Instagram의 게시 기록, 지표, 채널 분석연결하는 동안 사용자가 지울 때까지 보관합니다. 연결을 해제하면 이 컴퓨터에 따로 모아 30일 동안만 보관하고, 같은 계정을 다시 연결하면 이어 붙입니다. 30일이 지나면 fishcut이 실행 중일 때 삭제합니다. Instagram 댓글 글은 해제와 함께 바로 지웁니다.
사용자가 작성한 문구, 채널 기획, 업로드 초안과 선택, OAuth 클라이언트 파일, 프로젝트 파일사용자가 바꾸거나 지울 때까지 보관합니다. Google 권한 취소나 API 기록 정리만으로 작성 내용과 프로젝트 파일을 삭제하지 않습니다.
방침 동의 버전과 시각상태 폴더에 보관하며 다른 버전에 다시 동의하면 갱신합니다. 같은 버전에 다시 동의해도 최초 동의 시각을 바꾸지 않습니다. 상태 폴더를 삭제하면 함께 지워집니다.

마지막 확인 시각이 없는 기존 연결에는 새 보관기한을 임의로 부여하지 않습니다. 자동 정리를 중단하고, 별도 검증에서 Google이 같은 채널을 확인한 경우에만 실제 확인 시각을 기록합니다.

실행 조건: fishcut을 종료했거나 컴퓨터가 꺼져 있거나 잠든 동안에는 Google 확인과 디스크 삭제를 실행할 수 없습니다. 다시 시작하면 보관기한을 먼저 검사합니다. 네트워크가 끊기면 Google 확인과 권한 취소 요청을 완료할 수 없습니다. 이 제한 때문에 현재 로컬 실행 방식으로 오프라인 기간을 포함한 달력 기준 삭제 기한을 보장하지 않습니다.

9. 삭제와 권한 취소

  • 채널 관리에서 YouTube 연결을 해제하거나 연결된 프로필을 삭제하면 먼저 연결 사용을 막고 Google에 토큰 취소를 바로 요청합니다. 같은 YouTube 채널이나 토큰을 쓰는 다른 로컬 프로필도 사용을 막습니다. 전송 중인 업로드가 있으면 먼저 완료 상태를 확인해야 합니다.
  • Google 취소 요청이 실패하면 성공으로 표시하지 않습니다. 화면에 취소 대기를 표시하며 직접 재시도할 수 있고, 편집기가 실행 중일 때 자동으로도 재시도합니다. Google 권한 취소와 로컬 정보 삭제는 구분합니다.
  • 연결 철회 시 관련 API 결과, 업로드 세션 URL과 중복 전송 확인용 해시를 철회 뒤 7일 안에 로컬에서 삭제합니다. 사용자가 작성한 문구, 기획, 초안과 프로젝트 파일은 보존합니다.
  • Google 계정 권한 관리에서도 권한을 취소할 수 있습니다. 편집기는 실행 중 주기적으로 연결을 확인하며, Google이 토큰 무효를 명시적으로 응답하면 해당 연결과 관련 API 기록을 삭제합니다. 네트워크 장애나 잘못된 설정만으로 권한 철회를 단정하지 않습니다.
  • 상태 폴더를 직접 지우는 것은 로컬 삭제이며 Google에 취소 요청을 보내거나 Keychain의 토큰을 지우지는 않습니다. Google 권한도 없애려면 위 권한 관리 화면에서 취소합니다.
  • 로컬 정보 삭제나 앱 권한 취소는 YouTube에 이미 올린 영상을 삭제하지 않습니다. YouTube의 영상과 데이터는 YouTube에서 관리합니다.
  • 채널 관리에서 TikTok 채널의 연결을 해제하면 Keychain의 토큰을 지우고 TikTok에 토큰 폐기를 요청하며, TikTok 지표 읽기를 멈춥니다. 그 채널의 게시 기록과 지표는 8절의 30일 동안만 이 컴퓨터에 따로 보관하다가 지웁니다. 보관 중인 데이터를 바로 없애려면 fishcut 상태 폴더를 지웁니다. TikTok 쪽에서 직접 끝내려면 TikTok 설정이나 TikTok 앱의 설정, 보안, 앱 권한 관리에서 fishcut을 제거합니다.
  • 채널 관리에서 Instagram 채널의 연결을 해제하면 Keychain의 토큰을 지우고 지표 읽기를 멈춥니다. 이때 fishcut이 Meta에 앱 권한 취소를 요청하지는 않으므로, 서비스 쪽에서 앱의 접근을 끝내려면 Facebook의 비즈니스 통합 설정에서 앱을 제거합니다(페이지와 Instagram 계정에 대한 접근이 끝납니다).
  • Facebook과 Instagram 데이터 삭제 안내: 운영자는 fishcut이 Meta에서 받는 정보의 사본을 갖고 있지 않으므로 운영자 쪽에서 지울 것이 없습니다. fishcut이 가진 정보를 지우려면 위 설명대로 채널 연결을 해제하거나 fishcut 상태 폴더를 지우고, 비즈니스 통합에서 앱을 제거해 접근을 끝냅니다. 질문은 15절의 주소로 보내 주세요.
  • 이 컴퓨터의 정보를 지워도 Instagram에 이미 올린 릴스와 TikTok의 초안, 게시물은 삭제되지 않습니다. 그 데이터는 각 서비스에서 관리합니다.
  • 자동 처리에는 8절의 실행 조건이 적용됩니다. 운영체제 백업과 스냅샷, 사용자가 따로 복제한 상태 폴더까지 찾아 안전 삭제한다고 보장하지 않습니다.

10. 기기 저장과 쿠키

  • fishcut 소프트웨어는 사용자의 컴퓨터에 상태 폴더(토큰, 채널, 업로드 기록)와 작업 폴더를 만듭니다.
  • 로컬 에디터는 시작 토큰으로 연 브라우저만 에디터를 쓰도록 세션 쿠키를 둡니다. 화면 설정 같은 편의 정보를 브라우저 저장소에 둘 수 있습니다. 이 쿠키와 저장소는 이 컴퓨터의 에디터 주소에만 쓰입니다.
  • 이 웹사이트는 쿠키와 분석 도구를 쓰지 않습니다. 글꼴을 외부 글꼴 서비스(jsDelivr, Google Fonts)에서 받아 오고 호스팅 사업자를 거쳐 제공하므로, 이 사업자들이 접속 기록(IP 주소, 브라우저 정보)을 남길 수 있습니다.
  • 홈의 예시 쇼츠에서 YouTube 영상의 재생 버튼을 누르면 그 카드에 YouTube 플레이어(youtube-nocookie.com)를 불러옵니다. 누르기 전에는 YouTube로 요청을 보내지 않습니다. 플레이어가 열린 뒤에는 YouTube가 쿠키나 브라우저 저장소를 쓸 수 있고, 그 정보에는 Google 개인정보처리방침이 적용됩니다.

11. 광고와 제3자 콘텐츠

fishcut과 이 웹사이트는 광고를 싣지 않고, 제3자가 콘텐츠나 광고를 넣도록 허용하지 않습니다. 이 웹사이트의 YouTube 플레이어는 방문자가 재생을 누른 예시 쇼츠에만 열리고, 플레이어 안에 보이는 내용은 YouTube가 정합니다.

12. Google 사용자 데이터의 제한적 사용

fishcut이 Google API에서 받은 정보를 사용하고 다른 앱으로 보내는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

fishcut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google 사용자 데이터는 위 5절의 기능에만 씁니다.
  • 운영자는 Google 사용자 데이터를 받지 않으므로 운영자가 그 데이터를 읽지 않습니다.
  • Google 사용자 데이터를 AI나 머신러닝 모델 학습에 쓰지 않고, 판매하거나 광고에 쓰지 않습니다.

13. 아동

fishcut은 아동을 대상으로 만든 서비스가 아니며 아동의 정보를 일부러 수집하지 않습니다. 올리는 영상이 아동용인지는 업로드할 때마다 사용자가 지정합니다.

14. 방침 변경

이 방침을 바꾸면 이 페이지의 갱신일을 고칩니다. 편집기는 fishcut 개인정보처리방침, fishcut 이용약관, YouTube 서비스 약관과 Google 권한 취소 링크를 보여 줍니다. 사람이 기본으로 선택되지 않은 체크박스와 별도 동의 버튼으로 세 방침과 약관에 명시적으로 동의합니다. 동의 버전과 시각은 로컬 게시 상태에 기록하며 에이전트가 대신 동의할 수 없습니다.

여기서 설명한 앱 안의 동의 단계는 YouTube 채널을 연결할 때 적용됩니다. Instagram과 TikTok 연결에는 이 단계가 없으며, 처리 방식은 이 페이지의 3절과 9절에서 설명합니다.

기존 Google 연결을 방침 동의로 간주하지 않으며, 이미 연결한 채널은 재연결 없이 별도로 동의할 수 있습니다. 서버는 Google 연결과 업로드 검토/전송 전에 현재 동의 버전을 확인합니다. 초안 편집/저장과 연결 해제/취소 재시도는 방침 동의와 별개지만, 저장 보호 오류가 있으면 7절처럼 중단할 수 있습니다.

앱이 요구하는 동의 버전을 바꾸면 다시 동의해야 합니다. 웹페이지의 갱신일만 바꾸면 앱의 동의 버전도 자동으로 바뀌는 것은 아닙니다. 새로운 데이터 이용 방식이나 목적은 필요한 사전 고지와 동의 절차를 마련한 뒤 도입해야 합니다.
