YouTube 데이터와 개인정보

YouTube 연결과 데이터

fishcut은 YouTube API Services를 사용합니다. YouTube 업로드는 선택 기능이고, 연결하지 않아도 제작과 편집은 모두 쓸 수 있습니다.

fishcut은 YouTube에 영상을 올릴 수 있는 도구입니다. YouTube나 Google과 제휴하거나 보증받지 않았습니다.

요청하는 권한
권한쓰는 곳
youtube.upload사람이 확인한 최종 영상을, 사람이 정한 제목, 설명, 공개 범위로, 연결한 채널에 올릴 때만 씁니다.
youtube.readonly업로드할 채널의 이름과 ID를 보여 주고, 업로드 뒤 공개 상태와 예약 시각을 다시 확인할 때 씁니다.

  • 이 컴퓨터에만 저장

    Google 토큰, 연결한 채널의 이름과 ID, 업로드 기록은 이 컴퓨터의 상태 폴더에만 저장합니다. NomaDamas 서버로 보내지 않습니다. NomaDamas는 이 데이터를 받지 않습니다.

  • Google로만 전송

    업로드와 채널 확인 요청은 이 컴퓨터에서 Google과 YouTube로 바로 갑니다. 중간 서버가 없습니다.

  • 사람이 눌러야 업로드

    공개 범위, 아동용, 합성 콘텐츠, 예약 시각을 검토하고 마지막 버튼을 사람이 누릅니다.

  • 언제든 연결 해제

    에디터에서 연결을 해제하면 토큰을 Google에 취소 요청하고 이 컴퓨터에서 지웁니다. Google 계정 권한 관리에서도 권한을 취소할 수 있습니다.

fishcut이 Google API에서 받은 정보를 사용하고 다른 앱으로 보내는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

fishcut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

곧 공개합니다

fishcut은 지금 공개 준비 중입니다. 저장소를 공개하면 이 자리에 설치 방법을 올립니다. 공개 소식은 GitHub와 YouTube 채널에서 알립니다.

GitHub에서 보기

YouTube 업로드를 쓰려면

  1. Google Cloud에서 내 프로젝트를 만들고 YouTube Data API v3를 켭니다.
  2. 데스크톱 앱 OAuth 클라이언트를 만들고 JSON 파일을 받습니다.
  3. 에이전트에게 그 파일을 넣어 달라고 하거나 fishcut youtube import <파일>⁠을 실행합니다.
  4. 에디터의 채널 관리에서 "Google로 연결"을 누릅니다.

자주 묻는 질문

내 영상과 토큰은 어디로 가나요?

이 컴퓨터에 남습니다. 업로드할 때 영상 파일과 설정이 이 컴퓨터에서 YouTube로 바로 갑니다. NomaDamas는 어떤 데이터도 받지 않습니다.

에이전트가 마음대로 올리지는 않나요?

올리지 않습니다. 에이전트는 업로드 설정 검토까지 준비하고, 마지막 업로드 버튼은 사람이 누릅니다.

무료인가요?

fishcut은 MIT 라이선스 오픈소스로 공개할 예정입니다. 무료 로컬 음성으로 끝까지 만들 수 있고, 유료 음성 API는 내 키를 넣고 승인할 때만 씁니다.

어떤 에이전트와 쓰나요?

Claude Code와 Codex입니다. 에디터가 열려 있으면 MCP로 같은 초안을 읽고 고칩니다.

어떤 컴퓨터에서 도나요?

macOS Apple Silicon에서 개발하고 확인합니다. Docker로 띄우는 실행 경로도 있습니다.
