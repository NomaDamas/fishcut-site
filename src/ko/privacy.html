1. 이 방침이 적용되는 곳

이 방침은 NomaDamas가 오픈소스로 배포하는 쇼츠 제작 도구 fishcut(명령줄 도구와 로컬 에디터)과 이 웹사이트에 적용됩니다.

  • fishcut은 사용자의 컴퓨터에서 실행됩니다. NomaDamas는 fishcut을 위한 서버를 운영하지 않으며, fishcut이 다루는 정보를 받거나 보관하지 않습니다.
  • NomaDamas가 등록한 Google Cloud 프로젝트로 연결하면 Google 동의 화면에 앱 이름 fishcut이 표시되고 이 방침이 적용됩니다.
  • 사용자가 직접 만든 OAuth 클라이언트로 연결하면 그 Google Cloud 프로젝트는 사용자가 관리합니다. 이때도 fishcut 소프트웨어가 정보를 다루는 방식은 이 방침과 같습니다.

2. YouTube API Services 사용

fishcut은 연결한 YouTube 채널을 확인하고 사용자가 확인한 영상을 올리기 위해 YouTube API Services를 사용합니다. YouTube 기능을 쓰면 Google 개인정보처리방침도 함께 적용됩니다. YouTube 서비스 약관은 이용약관에서 설명합니다.

3. 접근하고 저장하는 정보

YouTube 업로드는 선택 기능입니다. Google 계정을 연결하지 않으면 fishcut은 아래 Google 관련 정보를 다루지 않습니다.

4. 정보를 쓰는 목적

  • 업로드할 채널의 이름과 ID를 화면에 보여 주어 사용자가 맞는 채널인지 확인하게 합니다.
  • 사용자가 확인 버튼을 누른 영상을 사용자가 정한 설정으로 연결한 채널에 올립니다.
  • 업로드 뒤 영상의 공개 상태와 예약 시각이 요청한 값과 같은지 확인해 보여 줍니다.

fishcut은 이 정보를 광고, 프로필 작성, 판매, 신용 평가에 쓰지 않습니다.

5. 공유와 전송

  • fishcut은 위 정보를 NomaDamas나 다른 회사로 보내지 않습니다.
  • 채널 확인과 업로드 요청은 사용자의 컴퓨터에서 Google로 HTTPS를 거쳐 바로 갑니다. 중간 서버는 없습니다.
  • 사용자가 MCP로 연결한 AI 에이전트(Claude Code, Codex 등)는 에디터에 열린 프로젝트와 채널 설정의 이름을 읽을 수 있습니다. 어떤 에이전트를 연결할지는 사용자가 정하며, 그 에이전트 제공자의 방침이 함께 적용됩니다. fishcut은 Google 토큰을 MCP로 넘기지 않습니다.
  • 사용자가 유료 음성 공급자(Typecast, ElevenLabs 등)를 고르고 승인하면, 음성을 만들 문장이 사용자의 API 키로 그 공급자에게 전송됩니다. 이때 그 공급자의 방침이 적용됩니다. 이 전송에 Google 사용자 데이터는 들어가지 않습니다.

6. 저장 위치와 보호

  • 상태 폴더는 fishcut을 실행한 사용자만 읽고 쓸 수 있는 권한(폴더 0700, 파일 0600)으로 만듭니다. Docker로 실행하면 그 설치의 state 볼륨에 둡니다.
  • Google과의 통신은 모두 HTTPS로 암호화됩니다.
  • 로컬 에디터는 이 컴퓨터의 주소(127.0.0.1)에서만 접속을 받고, 시작할 때 받은 토큰으로 연 브라우저만 쓸 수 있습니다.

8. 삭제와 권한 취소

  • 에디터의 채널 관리에서 연결을 해제하면, fishcut이 Google에 토큰 취소를 바로 요청하고 7일 안에 이 컴퓨터의 관련 정보를 지웁니다.
  • Google 계정 권한 관리 화면에서도 권한을 취소할 수 있습니다. 이때 fishcut은 다음 사용 때 토큰이 무효인 것을 확인하고 30일 안에 관련 정보를 지웁니다.
  • fishcut 상태 폴더를 직접 지워도 됩니다. NomaDamas는 이 정보를 갖고 있지 않으므로 삭제는 사용자의 컴퓨터에서 바로 끝납니다.
  • 이 컴퓨터에서 정보를 지워도 YouTube에 이미 올린 영상과 YouTube가 저장한 데이터에는 영향이 없습니다. 그 데이터는 YouTube에서 관리합니다.

9. 기기 저장과 쿠키

  • fishcut 소프트웨어는 사용자의 컴퓨터에 상태 폴더(토큰, 채널, 업로드 기록)와 작업 폴더를 만듭니다.
  • 로컬 에디터는 시작 토큰으로 연 브라우저만 에디터를 쓰도록 세션 쿠키를 둡니다. 화면 설정 같은 편의 정보를 브라우저 저장소에 둘 수 있습니다. 이 쿠키와 저장소는 이 컴퓨터의 에디터 주소에만 쓰입니다.
  • 이 웹사이트는 쿠키와 분석 도구를 쓰지 않습니다. 글꼴을 외부 글꼴 서비스(jsDelivr, Google Fonts)에서 받아 오고 호스팅 사업자를 거쳐 제공하므로, 이 사업자들이 접속 기록(IP 주소, 브라우저 정보)을 남길 수 있습니다.

10. 광고와 제3자 콘텐츠

fishcut과 이 웹사이트는 광고를 싣지 않고, 제3자가 콘텐츠나 광고를 넣도록 허용하지 않습니다.

11. Google 사용자 데이터의 제한적 사용

fishcut이 Google API에서 받은 정보를 사용하고 다른 앱으로 보내는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

fishcut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google 사용자 데이터는 위 4절의 기능에만 씁니다.
  • NomaDamas는 Google 사용자 데이터를 받지 않으므로 사람이 그 데이터를 읽지 않습니다.
  • Google 사용자 데이터를 AI나 머신러닝 모델 학습에 쓰지 않고, 판매하거나 광고에 쓰지 않습니다.

12. 아동

fishcut은 아동을 대상으로 만든 서비스가 아니며 아동의 정보를 일부러 수집하지 않습니다. 올리는 영상이 아동용인지는 업로드할 때마다 사용자가 지정합니다.

13. 방침 변경

이 방침을 바꾸면 이 페이지의 갱신일을 고칩니다. fishcut이 이 방침에 없던 방식이나 목적으로 정보를 다루게 되면, fishcut 안에서 바뀐 방침에 다시 동의를 받습니다.
