fishcut이 어떤 정보를 어디에 저장하고 어디에 쓰는지 설명합니다. fishcut은 사용자의 컴퓨터에서 실행되는 소프트웨어이고, NomaDamas는 사용자의 데이터를 받지 않습니다.

시행일 2026-10-27 / 마지막 갱신 2026-10-27

현재 실행본의 처리와 한계를 설명합니다. 종료하거나 잠든 컴퓨터에서는 자동 삭제와 Google 확인을 실행할 수 없습니다. 이 방침의 발행은 Google 심사 통과나 오프라인 삭제 기한의 예외 승인을 뜻하지 않습니다. 실행 조건은 7절, 저장 보호는 6절을 확인해 주세요.

1. 이 방침이 적용되는 곳

이 방침은 NomaDamas가 오픈소스 공개를 준비하는 쇼츠 제작 도구 fishcut(명령줄 도구와 로컬 에디터)과 이 웹사이트에 적용됩니다. NomaDamas는 (주)Markr가 운영하는 AI 오픈소스 해커하우스입니다.

  • fishcut은 사용자의 컴퓨터에서 실행됩니다. NomaDamas는 fishcut을 위한 서버를 운영하지 않으며, fishcut이 다루는 정보를 받거나 보관하지 않습니다.
  • NomaDamas가 등록한 Google Cloud 프로젝트로 연결하면 Google 동의 화면에 앱 이름 fishcut이 표시되고 이 방침이 적용됩니다.
  • 사용자가 직접 만든 OAuth 클라이언트로 연결하면 그 Google Cloud 프로젝트는 사용자가 관리합니다. 이때도 fishcut 소프트웨어가 정보를 다루는 방식은 이 방침과 같습니다.

2. YouTube API Services 사용

fishcut은 연결한 YouTube 채널을 확인하고 사용자가 확인한 영상을 올리기 위해 YouTube API Services를 사용합니다. YouTube 기능을 쓰면 Google 개인정보처리방침도 함께 적용됩니다. YouTube 서비스 약관은 이용약관에서 설명합니다.

3. 접근하고 저장하는 정보

YouTube 업로드는 선택 기능입니다. Google 계정을 연결하지 않으면 fishcut은 아래 Google 관련 정보를 다루지 않습니다.

4. 정보를 쓰는 목적

  • 업로드할 채널의 이름과 ID를 화면에 보여 주어 사용자가 맞는 채널인지 확인하게 합니다.
  • 사용자가 확인 버튼을 누른 영상을 사용자가 정한 설정으로 연결한 채널에 올립니다.
  • 예약 업로드 뒤 영상의 공개 상태와 예약 시각이 요청한 값과 같은지 다시 확인해 보여 줍니다. 예약하지 않은 업로드는 업로드 응답을 결과로 기록합니다.
  • 사용자가 MCP로 연결한 AI 에이전트가 영상 기획과 업로드 준비를 도울 수 있도록, 연결한 채널의 이름과 업로드 기록을 에이전트가 읽게 합니다(5절).

fishcut은 이 정보를 광고, 프로필 작성, 판매, 신용 평가에 쓰지 않습니다.

5. 공유와 전송

  • fishcut은 위 정보를 NomaDamas로 보내지 않습니다. Google 요청, 사용자가 연결한 AI 에이전트와 음성 공급자에 대한 전송은 아래와 같습니다.
  • 채널 확인과 업로드 요청은 사용자의 컴퓨터에서 Google로 HTTPS를 거쳐 바로 갑니다. 중간 서버는 없습니다.
  • 사용자가 MCP로 연결한 AI 에이전트(Claude Code, Codex 등)는 에디터가 이 컴퓨터에 저장한 정보 가운데 영상 프로젝트, 채널 설정(채널 이름, 기획 설정, 업로드 기본값, 기본 목소리, 게시 일정, 연결한 YouTube 채널의 이름), 업로드 기록(채널 이름, 시각, 공개 범위나 예약, 영상 주소, 보낸 제목, 고정 댓글)을 읽을 수 있습니다. 어떤 에이전트를 연결할지는 사용자가 정하며, 그 에이전트 제공자의 방침이 함께 적용됩니다. fishcut은 Google 토큰과 YouTube 채널 ID를 MCP로 넘기지 않습니다.
  • 사용자가 유료 음성 공급자(Typecast, ElevenLabs 등)를 고르고 승인하면, 음성을 만들 문장이 사용자의 API 키로 그 공급자에게 전송됩니다. 이때 그 공급자의 방침이 적용됩니다. 이 전송에 Google 사용자 데이터는 들어가지 않습니다.

6. 저장 위치와 보호

  • 상태 폴더는 fishcut을 실행한 사용자만 읽고 쓸 수 있는 권한(폴더 0700, 파일 0600)으로 만듭니다. Docker로 실행하면 그 설치의 state 볼륨에 둡니다.
  • 갱신 토큰은 현재 로컬 SQLite DB에 저장합니다. fishcut 자체의 저장 암호화나 OS 키체인 보관은 아직 구현하지 않았습니다. 파일 접근 권한과 저장 암호화는 다른 보호 수단입니다.
  • Google과의 통신은 모두 HTTPS로 암호화됩니다.
  • 로컬 에디터는 이 컴퓨터의 주소(127.0.0.1)에서만 접속을 받고, 시작할 때 받은 토큰으로 연 브라우저만 쓸 수 있습니다.

7. 보관 기간

fishcut은 연결한 YouTube 채널 확인과 사용자가 승인한 업로드에 필요한 정보를 이 컴퓨터에 저장합니다. 아래 자동 처리는 편집기가 실행 중일 때만 작동합니다.

정보보관 기간
YouTube 채널 ID와 이름, OAuth 갱신 토큰주기적으로 연결을 확인하고 성공한 실제 시각을 기록합니다. 마지막 확인부터 30일이 지난 정보와 토큰은 유지보수 실행 시 삭제합니다. 실패한 확인이나 재시작으로 확인 시각을 연장하지 않습니다.
YouTube 업로드 결과, 영상 ID와 주소, 업로드 세션 URL, 중복 전송 확인용 해시생성부터 30일이 지난 기록은 유지보수 실행 시 함께 삭제합니다. 채널 재확인으로 기록의 보관기한을 연장하지 않습니다. 편집기에서 연결을 철회하면 관련 기록은 즉시 로컬에서 삭제합니다.
Google 취소 요청에 실패한 갱신 토큰연결 사용을 막고 재시도에만 사용합니다. 철회 시작부터 7일이 지난 토큰은 유지보수 실행 시 삭제합니다. 로컬 삭제는 Google 권한 취소 성공을 뜻하지 않습니다.
사용자가 작성한 문구, 채널 기획, 업로드 초안과 선택, OAuth 클라이언트 파일, 프로젝트 파일사용자가 바꾸거나 지울 때까지 보관합니다. Google 권한 취소나 API 기록 정리만으로 작성 내용과 프로젝트 파일을 삭제하지 않습니다.

마지막 확인 시각이 없는 기존 연결에는 새 보관기한을 임의로 부여하지 않습니다. 자동 정리를 중단하고, 별도 검증에서 Google이 같은 채널을 확인한 경우에만 실제 확인 시각을 기록합니다.

실행 조건: 편집기를 종료했거나 컴퓨터가 꺼져 있거나 잠든 동안에는 Google 확인과 디스크 삭제를 실행할 수 없습니다. 다시 시작하면 보관기한을 먼저 검사합니다. 네트워크가 끊기면 Google 확인과 권한 취소 요청을 완료할 수 없습니다. 이 제한 때문에 현재 로컬 실행 방식으로 오프라인 기간을 포함한 달력 기준 삭제 기한을 보장하지 않습니다.

8. 삭제와 권한 취소

  • 채널 관리에서 YouTube 연결을 해제하거나 연결된 프로필을 삭제하면 먼저 연결 사용을 막고 Google에 토큰 취소를 바로 요청합니다. 같은 YouTube 채널이나 토큰을 쓰는 다른 로컬 프로필도 사용을 막습니다. 전송 중인 업로드가 있으면 먼저 완료 상태를 확인해야 합니다.
  • Google 취소 요청이 실패하면 성공으로 표시하지 않습니다. 화면에 취소 대기를 표시하며 직접 재시도할 수 있고, 편집기가 실행 중일 때 자동으로도 재시도합니다. Google 권한 취소와 로컬 정보 삭제는 구분합니다.
  • 연결 철회 시 관련 API 결과, 업로드 세션 URL과 중복 전송 확인용 해시를 로컬에서 삭제합니다. 사용자가 작성한 문구, 기획, 초안과 프로젝트 파일은 보존합니다.
  • Google 계정 권한 관리에서도 권한을 취소할 수 있습니다. 편집기는 실행 중 주기적으로 연결을 확인하며, Google이 토큰 무효를 명시적으로 응답하면 해당 연결과 관련 API 기록을 삭제합니다. 네트워크 장애나 잘못된 설정만으로 권한 철회를 단정하지 않습니다.
  • 상태 폴더를 직접 지우는 것은 로컬 삭제이며 Google에 취소 요청을 보내지는 않습니다. Google 권한도 없애려면 위 권한 관리 화면에서 취소합니다.
  • 로컬 정보 삭제나 앱 권한 취소는 YouTube에 이미 올린 영상을 삭제하지 않습니다. YouTube의 영상과 데이터는 YouTube에서 관리합니다.
  • 자동 처리에는 7절의 실행 조건이 적용됩니다. 운영체제 백업과 스냅샷, 사용자가 따로 복제한 상태 폴더까지 찾아 안전 삭제한다고 보장하지 않습니다.

9. 기기 저장과 쿠키

  • fishcut 소프트웨어는 사용자의 컴퓨터에 상태 폴더(토큰, 채널, 업로드 기록)와 작업 폴더를 만듭니다.
  • 로컬 에디터는 시작 토큰으로 연 브라우저만 에디터를 쓰도록 세션 쿠키를 둡니다. 화면 설정 같은 편의 정보를 브라우저 저장소에 둘 수 있습니다. 이 쿠키와 저장소는 이 컴퓨터의 에디터 주소에만 쓰입니다.
  • 이 웹사이트는 쿠키와 분석 도구를 쓰지 않습니다. 글꼴을 외부 글꼴 서비스(jsDelivr, Google Fonts)에서 받아 오고 호스팅 사업자를 거쳐 제공하므로, 이 사업자들이 접속 기록(IP 주소, 브라우저 정보)을 남길 수 있습니다.
  • 홈의 예시 쇼츠에서 YouTube 영상의 재생 버튼을 누르면 그 카드에 YouTube 플레이어(youtube-nocookie.com)를 불러옵니다. 누르기 전에는 YouTube로 요청을 보내지 않습니다. 플레이어가 열린 뒤에는 YouTube가 쿠키나 브라우저 저장소를 쓸 수 있고, 그 정보에는 Google 개인정보처리방침이 적용됩니다.

10. 광고와 제3자 콘텐츠

fishcut과 이 웹사이트는 광고를 싣지 않고, 제3자가 콘텐츠나 광고를 넣도록 허용하지 않습니다. 이 웹사이트의 YouTube 플레이어는 방문자가 재생을 누른 예시 쇼츠에만 열리고, 플레이어 안에 보이는 내용은 YouTube가 정합니다.

11. Google 사용자 데이터의 제한적 사용

fishcut이 Google API에서 받은 정보를 사용하고 다른 앱으로 보내는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

fishcut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google 사용자 데이터는 위 4절의 기능에만 씁니다.
  • NomaDamas는 Google 사용자 데이터를 받지 않으므로 사람이 그 데이터를 읽지 않습니다.
  • Google 사용자 데이터를 AI나 머신러닝 모델 학습에 쓰지 않고, 판매하거나 광고에 쓰지 않습니다.

12. 아동

fishcut은 아동을 대상으로 만든 서비스가 아니며 아동의 정보를 일부러 수집하지 않습니다. 올리는 영상이 아동용인지는 업로드할 때마다 사용자가 지정합니다.

13. 방침 변경

이 방침을 바꾸면 이 페이지의 갱신일을 고칩니다. 현재 편집기에는 이 방침에 별도로 동의하거나 다시 동의하는 화면이 없습니다. 새로운 데이터 이용 방식이나 목적은 필요한 사전 고지와 동의 절차를 마련한 뒤 도입해야 합니다.
