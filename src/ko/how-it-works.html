1. 구조

fishcut 에디터는 사용자의 컴퓨터에서 실행되는 데스크톱 앱입니다. 화면과 명령줄(CLI)은 이 컴퓨터의 주소(127.0.0.1)에서 도는 데몬 하나를 함께 씁니다. 에디터는 Google 계정 연결과 YouTube 업로드 요청을 Google로 바로 보냅니다. 아래 구조도는 YouTube 연결을 보여 줍니다. YouTube 연결과 업로드에는 중간 서버가 없어서 운영자는 YouTube 토큰, 채널 정보, 영상을 받지 않습니다. TikTok과 Instagram 연결은 7절에서 설명합니다.

2. 연결부터 업로드까지

  1. OAuth 클라이언트 넣기

    오픈소스 저장소에는 OAuth 클라이언트 자격 증명을 넣을 수 없습니다. 사용자는 자기 Google Cloud 프로젝트에서 YouTube Data API v3를 켜고 데스크톱 앱 OAuth 클라이언트를 만든 뒤, 받은 JSON 파일을 fishcut youtube import <파일>로 넣습니다. 에이전트에게 맡겨도 됩니다.

  2. Google로 연결

    먼저 채널 관리에서 fishcut 개인정보처리방침, fishcut 이용약관과 YouTube 서비스 약관을 확인하고, 기본으로 선택되지 않은 체크박스와 별도 동의 버튼으로 사람이 동의합니다. 동의한 버전과 시각은 이 컴퓨터의 게시 상태에 저장됩니다. 기존 Google 연결만으로 동의한 것으로 보지 않으며, 이미 연결돼 있다면 다시 연결할 필요는 없습니다. 에이전트는 이 동의를 대신할 수 없습니다.

    그다음 "Google로 연결"을 누르면 시스템 기본 브라우저에서 Google 동의 화면이 열립니다. 앱 안의 내장 브라우저를 쓰지 않습니다. 동의 화면에서 앱 이름과 두 권한을 확인하고 허용하면, 에디터가 이 컴퓨터의 임시 주소로 결과를 받습니다(PKCE, state 검사). 이 Google 권한 허용은 에디터의 방침 동의와 별개입니다.

  3. 채널 확인

    연결이 끝나면 에디터가 youtube.readonly로 연결한 채널의 이름과 ID를 읽어 보여 줍니다. 업로드할 채널이 맞는지 이 화면에서 확인합니다.

  4. 업로드 설정 검토

    제목, 설명, 태그, 공개 범위(공개, 일부 공개, 비공개), 카테고리, 아동용 여부, 실제처럼 보이는 합성 콘텐츠 여부, 예약 시각을 정합니다. 채널 기본값이 미리 채워지지만 영상마다 바꿀 수 있고, 에디터가 입력값 뒤에 다른 글자를 덧붙이지 않습니다.

    서버는 설정 검토와 실제 전송 전에 현재 방침 버전의 동의를 다시 확인합니다. 필요한 동의가 없으면 전송하지 않습니다. 초안 편집과 저장은 방침 동의와 구분되며, 연결 해제와 권한 취소 재시도도 별도 기능입니다. 다만 암호화 상태나 키를 읽을 수 없으면 인증 정보를 쓰는 작업은 중단합니다.

  5. 사람이 확인하고 업로드

    검토 화면에서 최종 영상, 채널, 설정을 다시 보여 줍니다. 일반 업로드와 예약 업로드 모두 최종 버튼 옆에 YouTube 서비스 약관과 커뮤니티 가이드 준수, 저작권과 개인정보 보호에 관한 고지를 표시합니다. 사람이 "확인했고, YouTube에 업로드"를 눌러야 youtube.upload로 전송을 시작합니다. 에이전트는 이 버튼을 누를 수 없습니다.

  6. 업로드 뒤 상태 확인

    예약 업로드가 끝나면 youtube.readonly로 영상의 공개 상태와 예약 시각을 다시 읽어 요청한 값과 비교합니다. 예약하지 않은 업로드는 업로드 응답을 결과로 기록합니다.

3. 요청하는 권한

권한쓰는 곳쓰지 않는 곳
youtube.upload사람이 확인한 최종 영상을 사람이 정한 설정으로 연결한 채널에 올릴 때사람의 확인 없는 업로드, 다른 채널의 영상 변경
youtube.readonly업로드할 채널의 이름과 ID 표시, 예약 업로드 뒤 공개 상태와 예약 시각 확인시청 기록, 구독 목록 수집
yt-analytics.readonly연결한 채널 자신의 영상 지표(조회수, 평균 시청, 시청 유지율, 노출 수)를 지표 화면에 보여 줄 때다른 채널의 데이터 수집, 광고, 판매

fishcut이 Google API에서 받은 정보를 사용하고 다른 앱으로 보내는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

fishcut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. 저장하는 데이터

Google, TikTok, Instagram 토큰과 앱 비밀은 macOS Keychain에 저장하고 상태 폴더의 파일에는 두지 않습니다. 상태 폴더와 그 파일은 fishcut을 실행한 사용자만 읽고 쓸 수 있는 권한(0700, 0600)으로 만듭니다. 채널 정보, 업로드 기록, 지표, 사용자 작성 자료, 프로젝트와 OAuth 클라이언트 파일은 상태 폴더와 작업 폴더의 파일로 저장하며 따로 암호화하지 않습니다.

데이터쓰는 곳보관과 삭제
Google 갱신 토큰YouTube 요청 인증실제 연결 확인부터 30일이 지나면 유지보수 시 삭제합니다. 철회 요청 실패 시에는 사용을 막고 재시도용으로만 보관하며 철회 시작부터 7일이 지나면 유지보수 시 삭제합니다.
연결한 채널의 ID와 이름업로드할 채널 표시실행 중 주기적으로 확인하고, 마지막 확인부터 30일이 지나면 유지보수 시 삭제합니다. 연결을 철회하면 사용을 막습니다.
업로드 기록, 세션 URL과 중복 전송 확인용 해시업로드 결과 확인과 중복 전송 방지생성부터 30일이 지나면 유지보수 시 함께 삭제합니다. 편집기에서 연결을 철회하면 관련 기록을 즉시 로컬에서 삭제합니다.
업로드 설정(제목, 설명, 태그, 공개 범위 등)사용자가 입력한 값을 다음 업로드에 다시 쓰기사용자가 바꾸거나 지울 때까지 보관합니다.
OAuth 클라이언트 파일Google 연결사용자가 바꾸거나 지울 때까지 보관합니다.
TikTok과 Instagram 토큰업로드와 지표 읽기 요청 인증연결을 해제하면 Keychain에서 바로 지웁니다.
TikTok과 Instagram의 게시 기록과 지표지표 화면연결하는 동안 사용자가 지울 때까지 보관합니다. 연결을 해제하면 30일 동안만 따로 보관한 뒤 지웁니다.
방침 동의 버전과 시각사람의 동의 확인로컬 게시 상태에 보관합니다. 다른 버전에 다시 동의하면 동의 기록을 갱신합니다.

편집기 종료, 컴퓨터 종료나 절전 중에는 Google 확인과 디스크 삭제가 실행되지 않습니다. 오프라인 기간의 달력 기준 삭제 기한과 백업 삭제를 보장하지 않습니다. 이 설명은 Google의 준법 승인이 아닙니다. 자세한 기준은 개인정보처리방침의 보관 기간에 있습니다.

5. 권한 취소와 삭제

  1. 채널 관리에서 연결을 해제하면 먼저 연결 사용을 막고 Google에 토큰 취소를 요청합니다. 실패하면 취소 대기로 표시하고, 편집기 실행 중 다시 시도합니다. 로컬 기록 삭제와 Google 취소 성공은 구분합니다.
  2. Google 계정 권한 관리에서도 권한을 취소할 수 있습니다. 편집기는 실행 중 주기적으로 확인하며 Google이 토큰 무효를 명시적으로 응답하면 해당 연결과 관련 API 기록을 삭제합니다.
  3. 상태 폴더 삭제는 그 폴더의 로컬 데이터만 지우며 Google에 권한 취소 요청을 보내지 않습니다. OS 자격 증명 저장소의 키, 별도 프로젝트 파일, 백업, 이미 YouTube에 올라간 영상에는 영향이 없습니다.

6. 업로드 한도

YouTube Data API의 videos.insert 업로드 한도는 사용하는 Google Cloud 프로젝트에 적용됩니다. 실제 한도는 그 프로젝트의 할당량 화면에서 확인해야 합니다. fishcut의 증액 요청 제출은 승인이나 적용 완료를 뜻하지 않으며, 이 페이지는 하루 업로드 가능 횟수를 보장하지 않습니다.

7. TikTok과 Instagram 연결과 지표

YouTube 외에 TikTok과 Instagram 계정도 연결할 수 있습니다. 이 연결은 선택입니다. 처리 방식의 전체 설명은 개인정보처리방침의 3절에 있고, 여기서는 흐름만 설명합니다.

  1. 계정 연결

    채널 관리에서 TikTok이나 Instagram 연결을 누르면 시스템 기본 브라우저에서 그 서비스의 동의 화면이 열리고, 계정 소유자가 직접 권한을 허용합니다. fishcut은 로그인과 동의를 대신 누르지 않습니다. 로그인 결과는 이 컴퓨터의 일회용 주소(127.0.0.1)로 돌아옵니다. 앱 비밀이 필요한 코드 교환은 운영자가 운영하는 인증 중계 서버(auth.fishcut.aidenahn.com)가 하며, 이 서버는 토큰을 저장하지 않습니다. 토큰은 이 컴퓨터의 macOS Keychain에만 저장됩니다.

  2. 검토와 업로드

    검토 화면에서 영상, 대상 계정, 공개 범위를 확인하고 사람이 승인해야 영상을 보냅니다. 영상은 이 컴퓨터에서 서비스로 바로 갑니다. TikTok은 기본으로 받은편지함에 초안을 보내고, 사용자가 TikTok 앱에서 캡션과 공개 범위를 정해 게시합니다. 연결할 때 바로 게시를 따로 켠 경우에만 사용자가 고른 공개 범위로 프로필에 게시합니다.

  3. 지표 읽기

    지표 화면은 올린 영상이 어떤 성과를 냈는지 보여 줍니다. fishcut이 실행 중이면 6시간마다, 동기화 버튼을 누르면 바로 읽습니다. TikTok은 연결한 계정 자신의 프로필 지표(팔로워 수, 팔로잉 수, 전체 좋아요 수, 영상 수)와 영상 지표(조회수, 좋아요, 댓글, 공유)를 TikTok API로 읽습니다. 계정 소유자가 TikTok API for Business(Accounts API) 접근을 승인한 경우에는 평균 시청 시간, 완주율, 유입 경로 같은 영상 인사이트도 읽습니다. 읽은 값은 이 컴퓨터에만 저장하고 지표 화면에서 계정 소유자에게 보여 주는 데만 씁니다. 판매, 제3자 공유, 사용자 간 결합, 크리에이터 탐색, 순위, 광고에 쓰지 않습니다.

  4. 연결 해제와 권한 취소

    채널 관리에서 연결을 해제하면 토큰을 Keychain에서 지우고 지표 읽기를 멈춥니다. TikTok은 토큰 폐기도 요청합니다. 그 계정의 게시 기록과 지표는 30일 동안만 이 컴퓨터에 따로 보관한 뒤 지웁니다. TikTok에서 직접 끝내려면 TikTok 설정이나 TikTok 앱의 설정, 보안, 앱 권한 관리에서 fishcut을 제거합니다. Instagram은 Facebook의 비즈니스 통합 설정에서 앱을 제거합니다.
