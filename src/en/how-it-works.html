How uploads work

This page explains how fishcut connects to YouTube and uploads videos, what data it stores, and how to revoke access. It is gathered on one page for Google reviewers and for users connecting for the first time.

1. Architecture

The fishcut editor is a local web app that runs on your computer. Your browser opens the editor at this computer's address (127.0.0.1), and the editor sends Google account connection and YouTube upload requests directly to Google. There is no NomaDamas server in between, so NomaDamas does not receive tokens, channel information, or videos.

2. From connecting to uploading

  1. Add an OAuth client

    OAuth client credentials cannot be included in an open source repository. In your own Google Cloud project, turn on YouTube Data API v3 and create an OAuth client for a desktop app, then add the downloaded JSON file by running fishcut youtube import <file>. You can also leave this to your agent.

  2. Connect with Google

    In channel management, press "Google로 연결" (Connect with Google), and the Google consent screen opens in your system's default browser. fishcut does not use a browser built into the app. When you check the app name and the two permissions on the consent screen and allow them, the editor receives the result at a temporary address on this computer (PKCE, state check).

  3. Check the channel

    Once you are connected, the editor uses youtube.readonly to read the name and ID of the connected channel and shows them. On this screen, check that it is the channel you want to upload to.

  4. Review the upload settings

    Set the title, description, tags, visibility (public, unlisted, private), category, made for kids, realistic synthetic content, and scheduled time. Your channel defaults are filled in first, but you can change them for each video, and the editor does not add any other text after what you enter.

  5. A person checks and uploads

    The review screen shows the final video, the channel, and the settings again. The upload with youtube.upload starts only when a person presses "확인했고, YouTube에 업로드" (Checked, upload to YouTube). The agent cannot press this button. The current review screen does not yet display the YouTube Terms of Service notice.

  6. Check the status after upload

    After a scheduled upload, the editor uses youtube.readonly to read the video's visibility status and scheduled time again and compares them with your request. For an unscheduled upload, it records the upload response as the result.

4. Data fishcut stores

Access tokens are used only in memory during requests. The other items below are stored in the fishcut state folder on this computer. The folder is created with permissions that let only the user who runs fishcut read it (0700 for the folder, 0600 for files). When you run fishcut with Docker, it is kept in that installation's state volume. App-level token encryption at rest and OS keychain storage are not yet implemented.

The app also lacks a separate privacy-policy acceptance screen and the YouTube terms notice immediately before upload. This description is not Google compliance approval. 5. Revoking access and deleting data

  1. Disconnecting in channel management first disables the connection and asks Google to revoke the token. Failures are shown as pending and retried while the editor is running. Deleting local records is not the same as successful Google revocation.
  2. You can also revoke access on the Google Account permissions page. While running, the editor checks periodically and deletes the connection and related API records when Google explicitly reports an invalid token.
  3. Deleting the state folder removes only the local data in that folder and does not send Google a revocation request. Separate project files, backups and videos already uploaded to YouTube are not affected.

6. Upload limit

The YouTube Data API videos.insert upload allowance applies to the Google Cloud project you use. Check that project's quota screen for its actual limit. Submitting fishcut's increase request does not mean approval or allocation, and this page does not guarantee a daily upload count.
