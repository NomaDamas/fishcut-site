Open a CapCut draft and edit it with the same commands

fishcut is an open source editor that opens, renders and saves the plain-text drafts of CapCut (international). The screen and the CLI share one daemon, so a person and an AI agent edit the same video document.

  • CapCut draft compatibility

    The goal is to open CapCut (international) drafts and render them the same way, and the supported range keeps growing. Unknown fields are preserved and saved back, and resources that are not supported are reported with the reason. Encrypted drafts are not opened.

  • One edit for screen and CLI

    Edits a person makes on the canvas and timeline and edits an agent such as Claude Code, Codex, Cursor, Gemini or Pi makes through the CLI use the same commands and the same undo history.

  • Templates and shorts

    Start a 9:16 short from a screen frame and a script style template, then continue in the same project with reference analysis, voice, captions, sound effects, render and review.

  • Runs on your computer

    Projects and tokens are stored on this computer. External services such as voices are ones you choose and connect, and editing and rendering work without them.

From one sentence to upload

The agent makes the draft, and you fix and check it. The 8 steps fall into three groups. The screens and conversation come from the real project and production chat behind the short above; only the channel profile values in step 1 are examples.

Group 1. Hand off
Group 2. Draft (agent)
Group 3. Refine and upload (human)
1 / 8
  1. 01

    Group 1. Hand off

    Set channel guidelines

    Save each channel's purpose, audience, tone, voice, scheduled publish time, and upload defaults. The agent reads these guidelines when it writes a script.

  2. 02

    Group 1. Hand off

    Choose a template

    A template pairs a script style (tone, order, voice) with a frame (layout, render engine), made by analyzing shorts that took off. Styles include tip lists, product explainers, knowledge narration, stories from posts, and hands-on demos.

  3. 03

    Group 1. Hand off

    Ask in one sentence

    Tell your agent the topic in one sentence. If you don't name a template, the agent reads the source and suggests one, and you choose.

  4. 04

    Group 2. Draft (agent)

    Script and voice

    The agent writes the script with the template's few-shot source scripts as a reference, then makes voice for each sentence. You can choose a free local voice, a clone of your own voice, or a paid voice such as Typecast or ElevenLabs. Once the script is written, a person approves it before production, and voices that cost money are generated only after a separate approval.

  5. 05

    Group 2. Draft (agent)

    Caption timing and sound effects

    The generated voice is transcribed back to text so that every word gets a timestamp. Scenes, captions, highlights, and sound effects move in time with those timestamps.

  6. 06

    Group 2. Draft (agent)

    Render and automatic checks

    The short is rendered as a 9:16 MP4, and the result is inspected. The checks confirm size, codec, and length. They also find blank frames and cuts that flash by in under a second, and on-screen text such as email addresses or account IDs, and report when each one appears.

  7. 07

    Group 3. Refine and upload (human)

    Fix it in the editor

    Change text, position, and size on the canvas, and move and trim clips on the layer timeline. Your edits go straight into the draft that the daemon holds, and you can undo them. An agent edits the same draft through the CLI with the same commands, and its edits land in the same undo history.

  8. 08

    Group 3. Refine and upload (human)

    Check and upload to YouTube

    Connect the channel with your Google account, then review the title, description, tags, visibility (public, unlisted, private), made for kids, synthetic content, and scheduled time. A person presses the final upload button. The agent only prepares things up to the upload settings review. Instagram and TikTok accounts are published through the same review.

Publishing and metrics

Publish, then see how it performed

When creators connect their own YouTube, Instagram and TikTok accounts to fishcut, they can publish finished videos from it. Publishing sends only a video that a person has checked and approved on the review screen. The Metrics screen shows how each published video performed.

fishcut reads only the TikTok metrics of the connected account itself, and only after the account owner authorizes it on TikTok's consent screen. fishcut is not affiliated with or endorsed by TikTok, Instagram, Meta, YouTube or Google.

What the Metrics screen reads
ServiceMetrics read
TikTokThe profile metrics and video metrics (views, likes, comments, shares) of the connected account itself. When the account owner has authorized access through the TikTok API for Business (Accounts API), it also reads video insights such as average watch time, completion rate and traffic sources.
YouTubeThe connected channel's list of videos with views, likes, comment counts, average watch time and audience retention.
InstagramLikes, comment counts, views, reach and average watch time of the connected account's posts and reels.

  • Read only after you authorize

    TikTok metrics are read only after the account owner authorizes it. From TikTok, fishcut does not read accounts you have not connected or other people's accounts.

  • Stored only on this computer

    Tokens are stored in the macOS Keychain on this computer and metrics in a folder on this computer. There is no fishcut server that receives and stores metrics. The auth relay only exchanges login codes for tokens and refreshes and revokes TikTok tokens, and it does not store tokens.

  • No sale, no sharing

    The data is not sold or shared with third parties, not combined across users, and not used for creator discovery, ranking or advertising.

  • Revoke at any time

    Disconnecting in fishcut deletes the tokens and asks TikTok to revoke. You can also revoke in TikTok settings, or in the TikTok app under Settings, Security, Manage app permissions.

See how TikTok and Instagram connection and metrics work, see the TikTok section of the Privacy Policy

YouTube Data and privacy

YouTube connection and data

fishcut uses YouTube API Services. YouTube upload is optional, and you can use all production and editing features without connecting.

fishcut is a tool that can upload videos to YouTube. It is not affiliated with or endorsed by YouTube or Google.

Permissions fishcut requests
PermissionUsed for
youtube.uploadUsed only to upload the final video a person has checked to the connected channel, with the title, description, and visibility that person set.
youtube.readonlyUsed to show the name and ID of the channel you will upload to, and to check the visibility status and scheduled time again after an upload.
yt-analytics.readonlyUsed only to show the metrics of the connected channel itself (views, average watch time, audience retention, impressions) on the Metrics screen.

  • Stored only on this computer

    Google tokens, the connected channel's name and ID, and upload history are stored only in the state folder on this computer. They are not sent to the operator's server. The operator does not receive this data.

  • Sent only to Google

    Upload and channel check requests go directly from this computer to Google and YouTube. There is no server in between.

  • No upload until a person presses

    A person reviews visibility, made for kids, synthetic content, and scheduled time, then presses the final button.

  • Disconnect anytime

    When you disconnect in the editor, fishcut asks Google to revoke the token and deletes it from this computer. You can also revoke access in Google Account permissions.

When fishcut uses information it receives from Google APIs, or transfers that information to another app, it follows the Google API Services User Data Policy, including the Limited Use requirements.

fishcut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

To use YouTube upload

  1. Create your own project in Google Cloud and turn on YouTube Data API v3.
  2. Create an OAuth client for a desktop app and download its JSON file.
  3. Ask your agent to add that file, or run fishcut youtube import <file>⁠.
  4. In the editor's channel management, press "Google로 연결" (Connect with Google).

Frequently asked questions

Where do my videos and tokens go?

They stay on this computer. When you upload, the video file and settings go directly from this computer to YouTube, Instagram or TikTok. The operator does not receive videos, tokens or metrics. Only when you log in to TikTok or Instagram, and when a TikTok token is refreshed or revoked, does a request pass through the auth relay, which does not store tokens.

Will the agent upload on its own?

No. The agent prepares everything up to the upload settings review, and a person presses the final upload button.

Is it free?

fishcut is open source under the Apache-2.0 license. You can make a short from start to finish with free local voices, and paid voice APIs are used only when you add your own key and approve.

Which agents does it work with?

Any agent that can run commands and read skills, such as Claude Code, Codex, Cursor, Gemini, or Pi. fishcut is called through its CLI and skills, and an agent's edits land in the same undo history as the edits a person makes in the app.

How is TikTok data used?

It is used only to show the profile metrics and video metrics of the connected account itself on the Metrics screen. It is read only after the account owner authorizes it, stored only on this computer, and never sold, shared or combined across users. You can revoke access in TikTok settings at any time.
