From one sentence to upload

The agent makes the draft, and you fix and check it. The 8 steps fall into three groups. The screens and conversation come from the real project and production chat behind the short above; only the channel profile values in step 1 are examples.

Group 1. Hand off
Group 2. Draft (agent)
Group 3. Refine and upload (human)
1 / 8
  1. 01

    Group 1. Hand off

    Set channel guidelines

    Save each channel's purpose, audience, tone, voice, scheduled publish time, and upload defaults. The agent reads these guidelines when it writes a script.

  2. 02

    Group 1. Hand off

    Choose a template

    A template pairs a script style (tone, order, voice) with a frame (layout, render engine), made by analyzing shorts that took off. Styles include tip lists, product explainers, knowledge narration, stories from posts, and hands-on demos.

  3. 03

    Group 1. Hand off

    Ask in one sentence

    Tell Claude Code or Codex the topic in one sentence. If you don't name a template, the agent reads the source and suggests one, and you choose.

  4. 04

    Group 2. Draft (agent)

    Script and voice

    The agent writes the script with the template's few-shot source scripts as a reference, then makes voice for each sentence. You can choose a free local voice, a clone of your own voice, or a paid voice such as Typecast or ElevenLabs. Once the script is written, a person approves it before production, and voices that cost money are generated only after a separate approval.

  5. 05

    Group 2. Draft (agent)

    Caption timing and sound effects

    The generated voice is transcribed back to text so that every word gets a timestamp. Scenes, captions, highlights, and sound effects move in time with those timestamps.

  6. 06

    Group 2. Draft (agent)

    Render and automatic checks

    The short is rendered as a 9:16 MP4, and the result is inspected. The checks confirm size, codec, and length. They also find blank frames and cuts that flash by in under a second, and on-screen text such as email addresses or account IDs, and report when each one appears.

  7. 07

    Group 3. Refine and upload (human)

    Fix it in the editor

    Change text, position, and size on the canvas, and move and trim clips on the layer timeline. Your edits go straight into the draft on the local editor server, and you can undo them. While the editor is open, Claude Code and Codex also read and edit the same draft over MCP.

  8. 08

    Group 3. Refine and upload (human)

    Check and upload to YouTube

    Connect the channel with your Google account, then review the title, description, tags, visibility (public, unlisted, private), made for kids, synthetic content, and scheduled time. A person presses the final upload button. The agent only prepares things up to the upload settings review.

YouTube Data and privacy

YouTube connection and data

fishcut uses YouTube API Services. YouTube upload is optional, and you can use all production and editing features without connecting.

fishcut is a tool that can upload videos to YouTube. It is not affiliated with or endorsed by YouTube or Google.

Permissions fishcut requests
PermissionUsed for
youtube.uploadUsed only to upload the final video a person has checked to the connected channel, with the title, description, and visibility that person set.
youtube.readonlyUsed to show the name and ID of the channel you will upload to, and to check the visibility status and scheduled time again after an upload.

  • Stored only on this computer

    Google tokens, the connected channel's name and ID, and upload history are stored only in the state folder on this computer. They are not sent to a NomaDamas server. NomaDamas does not receive this data.

  • Sent only to Google

    Upload and channel check requests go directly from this computer to Google and YouTube. There is no server in between.

  • No upload until a person presses

    A person reviews visibility, made for kids, synthetic content, and scheduled time, then presses the final button.

  • Disconnect anytime

    When you disconnect in the editor, fishcut asks Google to revoke the token and deletes it from this computer. You can also revoke access in Google Account permissions.

When fishcut uses information it receives from Google APIs, or transfers that information to another app, it follows the Google API Services User Data Policy, including the Limited Use requirements.

fishcut's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

To use YouTube upload

  1. Create your own project in Google Cloud and turn on YouTube Data API v3.
  2. Create an OAuth client for a desktop app and download its JSON file.
  3. Ask your agent to add that file, or run fishcut youtube import <file>⁠.
  4. In the editor's channel management, press "Google로 연결" (Connect with Google).

Frequently asked questions

Where do my videos and tokens go?

They stay on this computer. When you upload, the video file and settings go directly from this computer to YouTube. NomaDamas does not receive any data.

Will the agent upload on its own?

No. The agent prepares everything up to the upload settings review, and a person presses the final upload button.

Is it free?

fishcut will be released as MIT-licensed open source. You can make a short from start to finish with free local voices, and paid voice APIs are used only when you add your own key and approve.

Which agents does it work with?

Claude Code and Codex. While the editor is open, they read and edit the same draft over MCP.

What computers does it run on?

It is developed and tested on macOS with Apple Silicon. You can also run it with Docker.
